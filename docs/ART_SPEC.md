# AFTERZERO art & platform contract

Shared contract for the realistic-human, environment-realism and mobile work.
Everything is generated by our own code at runtime. No downloaded models, photos,
scanned textures or third-party art. Three.js library code (vendor/) is allowed.

## Conventions
- Units: meters. +Y up. A character faces **+Z**. Character's **left = +X**.
- Renderer: three r170 (`vendor/`), ACES tone mapping, sRGB output, PMREM env maps.
- Target: phones first (mid-range Android / iPhone 12-class) and desktop.
- Headless test rendering in this container uses SwiftShader (CPU): expect 1-10 fps.
  Use small viewports and static frames for visual checks.

## 1. Head module — `createHead(params)` (src/human/head*.js)

```js
createHead({
  sex: 0..1,            // 0 = male, 1 = female (continuous)
  age: years,           // 8..75
  skin: 0xRRGGBB,       // base skin tone
  eyeColor: 0xRRGGBB,
  seed: int,
  shape: { jaw, cheek, nose, noseWidth, lips, brow, eyeSize, faceLength, chin }, // each -1..1, 0 = average
  marks: { scar: bool, freckles: 0..1, wrinkles: 0..1, stubble: 0..1 },
  detail: 'high' | 'low',
}) => {
  group,                // THREE.Group; origin = head pivot (top of neck); parent it to the head bone
  skinMaterial,         // the face/neck skin material (body should match its tone)
  setGaze(worldPos|null), setBlink(0..1), setMouth(0..1 open), setSmile(0..1),
  update(dt),           // optional micro-motion (saccades), may be a no-op
  scalp: { geometry, center: THREE.Vector3, radius }, // base head surface in group space for hair projection
  landmarks: { eyeL, eyeR, noseTip, mouth, chin, crown, earL, earR }, // THREE.Vector3 in group space
  dispose(),
}
```

Dimensions in group space for an adult male (female ≈ 0.94×, scale children by age):
| landmark | position (x, y, z) m |
|---|---|
| pivot (top of neck, jaw-angle level) | 0, 0, 0 |
| chin | 0, -0.035, +0.085 |
| mouth center | 0, +0.005, +0.100 |
| nose tip | 0, +0.045, +0.120 |
| eye centers | ±0.032, +0.085, +0.075 |
| brow | 0, +0.110, +0.095 |
| crown (top of skull) | 0, +0.195, 0 |
| back of skull | 0, +0.08, -0.105 |
| ears (center) | ±0.075, +0.070, -0.010 |
| neck stub | from y=0 down to y=-0.09, radius 0.055 (female 0.047), center z≈-0.01 |

Requirements:
- One continuous skin surface for face, skull and neck stub. No visible primitive seams.
- Real anatomy: skull mass, brow ridge, eye sockets with upper/lower lids and a lid crease,
  nose bridge/tip/alae/nostrils, philtrum, defined upper and lower lips, nasolabial fold,
  cheekbones, jawline and chin, sculpted ears. Faces must read as specific adult humans,
  never as a doll, toy, mannequin or brick figure.
- Eyes: separate eyeballs with sclera (subtle veins), radial iris with limbal ring, dark pupil,
  glossy cornea highlight; they rotate for gaze. Eyelids close for blink (morph target).
- Skin: procedurally generated albedo (tone variation, redness on cheeks/nose/ears, lips),
  normal map (pores, fine creases; wrinkles scale with age), roughness map (oilier T-zone),
  and a subsurface-scattering approximation (wrap lighting / sheen / transmission tint).
- Mouth open morph shows a dark mouth interior and teeth.
- Budget: high ≤ 24k triangles total for the head; low ≤ 3k.
- Hair is NOT part of the head module (see §3). The head must look good bald and with hair.

## 2. Body module — `createBody(params)` (src/human/body*.js)

```js
createBody({
  height: m, sex: 0..1, build: 0.8..1.25, age: years, skin: 0xRRGGBB, seed: int,
  detail: 'high' | 'low',
  outfit: {
    top:   { type: 'jacket'|'tshirt'|'sweater'|'tunic'|'uniform'|'armored'|'none', color, material: 'leather'|'fabric'|'synthetic' },
    vest:  { color } | null,         // hi-vis / tactical vest over the top
    coat:  { type: 'long'|'lab', color, material } | null,
    pants: { type: 'trousers'|'cargo'|'wraps', color },
    shoes: { type: 'boots'|'shoes'|'sandals', color },
    gloves: color|null, belt: color|null, sash: color|null, strap: bool, bracelets: color|null, wristMark: bool,
  },
}) => {
  root,                 // THREE.Group containing SkinnedMesh(es) bound to one THREE.Skeleton
  skeleton,             // THREE.Skeleton
  bones: { hips, spine, chest, neck, head,
           shoulderL, upperArmL, forearmL, handL, shoulderR, upperArmR, forearmR, handR,
           thighL, shinL, footL, thighR, shinR, footR },
  sockets: { handL, handR, back },   // Object3Ds for props (umbrella, etc.)
  wristRing,            // emissive ring mesh on forearmL when outfit.wristMark, else null
  materials,            // { skin, ...cloth } for tinting / ghosting
  dispose(),
}
```

Skeleton and rest pose:
- Rest pose: standing, legs straight down, arms hanging at the sides ~10° out from the body.
- **Every bone's rest local rotation is identity** (bone axes aligned with the root), so
  `bone.rotation.x` swings a limb forward/back, `.z` abducts, `.y` twists. Rotating a
  hanging limb by a **negative** x swings it forward (toward +Z).
- `bones.head` origin = head pivot of §1 (attach `head.group` there). The body's neck
  rises to 2 cm above the pivot so it hides inside the head's neck stub.
- Adult male 1.80 m reference heights: hip joints 0.92, knees 0.50, ankles 0.08,
  navel 1.08, shoulder joints 1.46 (±0.19 x), neck base 1.52, head pivot 1.60, top of head 1.80.
  Upper arm 0.30, forearm 0.26, hand 0.19, thigh 0.42, shin 0.42. Scale everything by height/1.80;
  female: narrower shoulders, wider hips, smaller hands; build scales girth.
- Body: one continuous skinned skin surface (torso, arms, legs, hands with fingers, feet);
  smooth joints with no seams and correct skin weights (shoulders, elbows, hips, knees deform
  without collapsing). Clothing: separate skinned shells on the same skeleton with real
  garment features (collars, seams, cuffs, pockets, folds via normal maps). Skin fully
  covered by clothing must not poke through (omit or shrink it).
- Budget: high ≤ 30k triangles body+clothes; low ≤ 6k (crowds).

## 3. Hair module — `createHair(params, head)` (src/human/hair.js)
Hair cards / strand ribbons with procedurally drawn strand alpha textures and anisotropic
highlights, projected on `head.scalp`. Styles: messy, short, swept, grey-swept, long, bun, bald, buzz.
Also eyebrows, eyelashes, stubble/full beard. Mobile-safe transparency (alphaTest / alpha-to-coverage).
Budget: high ≤ 12k tris, low ≤ 1.5k.

## 4. Environment realism kit — src/world/realism.js
Physically based look on a mobile budget: sky-driven image-based lighting (PMREM of a procedural
sky), one-time cube-camera environment captures for reflective wet streets/floors, PBR texture sets
(albedo + normal + roughness [+ AO]) generated by code, interior-mapped building windows, terrain
splatting, procedural trees with leaf cards, instanced grass, water with fresnel reflection,
light shafts and atmospheric depth. Scene budget on phones: ≤ 250 draw calls, ≤ 700k triangles,
≤ 6 dynamic lights, ≤ 1 shadow-casting light.

## 5. Mobile
Touch controls, landscape play, safe areas, PWA install + offline cache, adaptive quality,
and a Capacitor scaffold for Android/iOS store builds. See docs/MOBILE_RELEASE.md.
